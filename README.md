#CyberShieldChatbot (PROG6221 - Part 1)

A robust, interactive C# console application designed to introduce users to foundational cybersecurity awareness while demonstrating professional software engineering principles, multimedia integration, and continuous integration workflows.

---

## Project Overview
CyberShieldChatbot is built to provide an engaging and secure terminal experience. Key features of Part 1 include:
* **Voice Greeting Integration:** Plays a startup greeting audio file (`greeting.wav`) using .NET's `System.Media.SoundPlayer`.
* **Enhanced Console UI:** Features custom ASCII art, borders, and colored console text for improved visual appeal and readability.
* **Interactive User Experience:** Captures the user's name and personalizes subsequent interactions.
* **Basic Response System:** Handles fundamental cybersecurity topics including password safety, phishing awareness, and safe browsing.
* **Robust Input Validation:** Gracefully catches empty or unrecognized inputs, preventing application crashes and providing helpful fallback responses.
